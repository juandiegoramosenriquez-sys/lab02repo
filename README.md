Registro de Notas - AppFinal.kt

Proyecto simple en Kotlin (consola) para registrar el nombre de un estudiante, la cantidad de cursos que lleva, y el nombre, crédito y costo de cada uno.

Prompts usados

Commit 1:

Crear una app simple en Kotlin que pida el nombre del estudiante y la cantidad de cursos que lleva.

Commit 2:

Agregar un bucle que pregunte el nombre y el crédito de cada curso, según la cantidad ingresada, y calcule el costo automáticamente (crédito x 100).

Commit 3:

Mostrar un resultado final con la tabla de cursos, el total de créditos, el total a pagar, la carga académica y la forma de pago en cuotas.
